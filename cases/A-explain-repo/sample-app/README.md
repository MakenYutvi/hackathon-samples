# Feature Board

Небольшой REST API доски фич-реквестов: пользователи создают идеи, голосуют,
а приоритет считается по голосам, свежести и оценке трудозатрат.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

API поднимется на `http://localhost:5000`.

## Эндпоинты

- `POST /users` — создать пользователя, вернуть токен.
- `GET /features` — список фич, отсортированный по приоритету.
- `POST /features` — создать фичу (нужен токен).
- `POST /features/<id>/vote` — проголосовать за фичу (нужен токен).
- `GET /features/<id>` — одна фича с деталями.

## Структура

- `app.py` — точка входа, сборка приложения.
- `config.py` — настройки.
- `models.py` — доменные модели.
- `storage.py` — хранилище данных.
- `scoring.py` — расчёт приоритета.
- `auth.py` — выдача и проверка токенов.
- `routes/` — HTTP-эндпоинты.
- `tests/` — тесты на расчёт приоритета.
