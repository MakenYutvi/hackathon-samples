# Кейс A. Объяснить незнакомый репозиторий

В папке [`sample-app/`](sample-app/) лежит небольшое реальное приложение. Это **доска фич-реквестов**: пользователи предлагают идеи и голосуют за них, а приоритет считается автоматически.

Задача: попросить агента прочитать код и объяснить его. Вы не должны уметь читать код — это делает агент.

## Что показать

1. Откройте папку `cases/A-explain-repo/sample-app/` в Codex.
2. Дайте промпт из [`../../PROMPTS.md`](../../PROMPTS.md) (раздел «Кейс A»).
3. Получите: описание продукта, карту модулей, Mermaid-схему, список рисков.

## Зачем это продакту/HR

- Так можно за минуты понять незнакомый продукт, legacy-сервис или чужой проект.
- «Объясни мне как продакту» снимает страх перед кодом: агент переводит технику на язык продукта.
- Список «архитектурных рисков» — готовый вход в разговор с инженерами.

## Подсказка ведущему

В коде намеренно оставлены типичные слабые места (хранение в памяти, наивная авторизация, отсутствие части валидации). Это материал для промпта про риски — агент должен их найти сам.
