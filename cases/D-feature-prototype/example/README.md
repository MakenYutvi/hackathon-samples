# Эталонный прототип (пример результата)

Это пример того, что должно получиться по продуктовому брифу `briefs/product-saved-views.md`.

Сначала попробуйте сгенерировать свой вариант через Codex, потом сравните.

## Как открыть

Откройте `index.html` двойным кликом в браузере.

## Что кликается

- **Чипы видов** сверху: «Все заявки» (`index.html`) и «Мои открытые» (`my-open.html`) — переключают список.
- **Фильтры** (Канал / Ответственный / Статус) — реально фильтруют список и обновляют счётчик «Показано заявок».
- **Строки заявок** — клик открывает экран заявки (`request.html`), назад — по ссылке «← к списку».
- **«+ Сохранить текущий вид»** → форма `save-view.html` (имя вида + захваченные фильтры) → `applied.html` (новый вид активен, список отфильтрован).

## Экраны

- `index.html` — список со всеми заявками.
- `my-open.html` — вид «Мои открытые».
- `request.html` — экран одной заявки.
- `save-view.html` — форма сохранения вида.
- `applied.html` — состояние после сохранения вида.
- `style.css` / `proto.js` — стиль и лёгкая интерактивность (фильтры, клик по строке).

Прототип намеренно чёрно-белый и простой: цель — обсудить сценарий и логику с командой, а не финальный визуал.
