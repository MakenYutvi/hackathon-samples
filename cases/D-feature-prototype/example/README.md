# Эталонный прототип (пример результата)

Это пример того, что должно получиться по продуктовому брифу `briefs/product-saved-views.md`.

Сначала попробуйте сгенерировать свой вариант через Codex, потом сравните.

## Как открыть

Откройте `index.html` двойным кликом в браузере. Кликайте по экранам:

1. `index.html` — список заявок + переключатель видов → «+ Сохранить текущий вид»
2. `save-view.html` — форма: имя вида + захваченные фильтры → «Сохранить»
3. `applied.html` — новый вид активен, список отфильтрован

Прототип намеренно чёрно-белый и простой: цель — обсудить сценарий и логику с командой, а не финальный визуал.
