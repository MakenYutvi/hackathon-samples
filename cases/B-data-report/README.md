# Кейс B. Данные → отчёт

В папке [`data/`](data/) лежат два CSV без всякой базы данных — агент читает их напрямую.

- `product-metrics.csv` — понедельные метрики продукта.
- `hr-hiring-funnel.csv` — помесячная воронка найма.
- `data-dictionary.md` — описание полей.

## Что показать

1. Откройте папку `cases/B-data-report/` в Codex.
2. Дайте промпт из [`../../PROMPTS.md`](../../PROMPTS.md) (раздел «Кейс B») — продуктовый или HR-овский.
3. Получите Markdown-отчёт: метрики, аномалии/узкие места, выводы, рекомендации.
4. Опционально: попросите собрать Excel с графиком.

## Зачем это продакту/HR

- Превратить «сырую выгрузку» в выводы за минуты, без ручного Excel.
- Агент не только считает, но и **находит аномалии** и предлагает гипотезы причин.
- Это ровно тот навык, который дальше переносится на твои реальные выгрузки.

## Граница

Агент считает и подсвечивает паттерны, но **решение и интерпретация — на человеке**. Цифры синтетические, проверяй логику выводов.
