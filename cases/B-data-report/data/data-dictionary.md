# Описание полей данных

Все данные синтетические.

## product-metrics.csv

Понедельные метрики SaaS-продукта за 26 недель 2026 года.

| Поле | Значение |
|---|---|
| `week` | Неделя в формате `2026-W01`. |
| `new_signups` | Новые регистрации за неделю. |
| `activated_users` | Пользователи, дошедшие до ключевого действия (активация). |
| `activation_rate_pct` | Доля активированных от новых, %. |
| `wau` | Weekly Active Users. |
| `mau` | Monthly Active Users (скользящее окно). |
| `churned_users` | Ушедшие за неделю. |
| `search_adoption_pct` | Доля активных, пользующихся ключевой фичей (поиск), %. |
| `nps` | Net Promoter Score. |
| `support_tickets` | Обращения в поддержку за неделю. |
| `mrr_usd` | Monthly Recurring Revenue, USD. |

Подсказка для проверки: где-то в середине периода метрики ведут себя не так, как в начале. Хороший разбор должен это заметить и предложить гипотезу.

## hr-hiring-funnel.csv

Помесячная воронка найма по подразделениям за 2026-01…2026-05.

| Поле | Значение |
|---|---|
| `month` | Месяц `2026-01`. |
| `department` | Подразделение. |
| `role` | Нанимаемая роль. |
| `applications` | Поданные заявки. |
| `phone_screens` | Телефонные/скрининговые интервью. |
| `onsite_interviews` | Очные/финальные интервью. |
| `offers` | Сделанные офферы. |
| `hires` | Принятые на работу. |
| `avg_days_to_hire` | Среднее время найма, дней. |
| `offer_accept_rate_pct` | Доля принятых офферов, %. |
| `primary_source` | Основной источник кандидатов. |

Подсказка для проверки: подразделения отличаются по качеству воронки. Где-то проблема на входе (много заявок, мало проходит), где-то — на выходе (офферы не принимают, найм затягивается). Хороший разбор должен найти конкретные узкие места, а не просто пересказать таблицу.
